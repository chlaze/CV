# Chloé Mendes — Personal CV Site

Product Project Manager · Fintech & Digital Banking

Personal portfolio site and CV. Built with vanilla HTML / CSS / JS — zero dependencies, deploys as static files.

## Files

- `index.html` — live portfolio site
- `styles.css` · `script.js` — site styling & interactive animations
- `chloe.jpg` — profile photo
- `cv-v1-fintech.html` · `cv-v2-swiss.html` · `cv-v3-warm.html` — three CV design variants (HTML source)
- `cv-ats.html` — ATS / AI-screening friendly CV (HTML source)
- `CV_v1_Fintech.pdf` · `CV_v2_Swiss_rev5.pdf` · `CV_v3_Warm.pdf` — visual CV PDFs
- `CV_ATS.pdf` — ATS-optimised CV PDF (recommended for online job portals)

## Deploy

Static site — drop the folder on Netlify, Vercel, Cloudflare Pages or GitHub Pages.
